### 3. `do_class_change/2` in `player_session.ex`
Private helper implementing full class change flow:
1. `ClassAdvancementTable.can_advance?/2` — validates transition
2. On failure: `CreatureSay{chat_type: 2, char_name: "System", ...}`
3. On success: update class_id in state, grant starting skills via `SkillLearnTable.get_learnable_skills(class_id, 1)`, call `broadcast_user_info/1` with updated state

### 4. `RequestGotoLobby` handler
Added `handle_packet` clause for `%RequestGotoLobby{}` — closes the player session and returns the client to the lobby/character select screen.
