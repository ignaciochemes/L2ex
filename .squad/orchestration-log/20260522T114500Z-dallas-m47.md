## Key Learnings Recorded

- Always include `defp handle_packet(` prefix (not just the pattern) when adding new packet handler clauses — missing the `defp` prefix causes a compilation syntax error.
- Quest in-memory map is keyed by `quest_id` (integer); the DB schema uses the same integer key.
