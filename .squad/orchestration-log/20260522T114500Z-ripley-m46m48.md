### 2. `L2E.Instance.Zone` (M48)
Created `lib/l2e/instance/zone.ex`. GenServer — one process per active instance. Holds:
- Template ID, party ID, door state map
- Player list with `Process.monitor` for crash cleanup
- TTL expiry via `Process.send_after(self(), :instance_expired, ttl)` — no polling

On `:instance_expired`: broadcasts `:instance_ejected` to all player sessions. On `:instance_player_down`: removes player from list. Door state is private to the Zone process — no shared locks, no global door registry.

### 3. `L2E.Instance.Manager` (M48)
Created `lib/l2e/instance/manager.ex`. GenServer with ETS registry:
- `{:party, party_id} => instance_pid`
- `{:instance, instance_pid} => template_id`
Reads are O(1) direct ETS; writes serialized through GenServer. `Process.monitor` on instance pids for cleanup on Zone crash. Calls `L2E.Instance.Supervisor.start_child` to create instances.
